Privacy policy

Waypoint · last updated 7 October 2026

Waypoint is a personal job-search tool that runs on its owner's own computer. It is used by one person, its owner, and is not offered to the public. This policy explains what it does with data, including data from Google.

Google user data it accesses

Waypoint requests one Google OAuth scope, https://www.googleapis.com/auth/drive.file. With it, Waypoint:

  • uploads PDF CVs that it generated to the owner's Google Drive;
  • replaces those same files when a CV is rebuilt, so their link stays the same;
  • sets those files to "anyone with the link can view", so the link works when the owner includes it in a message.

With this scope, Waypoint can only reach files it created. It does not read, list, change or delete any other file in the Drive.

How that data is stored

The Google OAuth credentials and the IDs and links of the uploaded files are kept only on the owner's computer, in a local configuration file and a local database. There is no Waypoint server, and nothing is sent to the developer.

Sharing

Google user data is not sold, not used for advertising, and not shared with any third party. The only place a CV link goes is a message the owner chooses to send. Anyone the owner gives that link to can open that one CV.

Waypoint also sends job-posting text and the owner's own profile to Anthropic's Claude to help tailor the CV and draft messages. No Google user data is part of that, and no Drive file contents or Drive metadata are sent.

Waypoint's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Other data

If the owner signs in with LinkedIn, Waypoint receives only their name, email address and profile photo. The owner can also import their own LinkedIn data export. All of it stays in the local database on the owner's computer.

Removing access and data

Access can be withdrawn at any time at myaccount.google.com/permissions. Uploaded CVs can be deleted from Google Drive like any other file. Deleting Waypoint's local database removes everything it stored.
